# Maintainers

This page lists the project maintainers and how to become one.

| Name | Role | Contact |
| --- | --- | --- |
| Marco Carvin | Reference owner, maintainer | m.carvin@errevi.com |

The reference owner is the default reviewer for all files, as set in
[CODEOWNERS](CODEOWNERS). The owner decides on merges, releases and security fixes,
and is the contact for questions about the project.

To request maintainer status, open an issue that describes your contributions to the
project. See [GOVERNANCE.md](GOVERNANCE.md) for how decisions are made.
