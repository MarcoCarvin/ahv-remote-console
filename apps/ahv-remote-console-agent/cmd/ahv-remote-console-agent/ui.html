Setting up the Guest Agent

This won't take long — keep this window open until it finishes.

Setup installs the agent for your user account and starts it at each sign-in. If the display resolution needs changing, Windows asks once for administrator permission so the agent can set this VM's startup resolution in its UEFI firmware. You can decline that prompt; the agent still sets the resolution at each sign-in.
