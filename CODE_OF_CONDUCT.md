# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behaviour

Be respectful, constructive and professional in issues, pull requests, reviews and
discussions. Harassment, personal attacks and publishing other people's private
information are not acceptable.

## Reporting

Report conduct concerns to a project maintainer, listed in
[MAINTAINERS.md](MAINTAINERS.md). Maintainers handle reports in confidence. They may
remove content, restrict participation or remove contributors who break these
standards.

Security vulnerabilities are not conduct reports. Follow [SECURITY.md](SECURITY.md).
